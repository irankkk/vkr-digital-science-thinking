# vkr-digital-science-thinking
Разработка проектного модуля для интеграции студентов медицинского вуза в научную деятельность.  

Цель: Разработать концепцию и спроектировать архитектуру проектного модуля для интеграции студентов медицинского вуза в научную деятельность, обеспечивающего системное вовлечение обучающихся в исследования, персонализацию научных траекторий и снижение барьеров входа в науку.

Задачи:
 1. Изучить предметную область организации студенческой науки в медицинских вузах и провести анализ существующих образовательных моделей и аналогов проектных модулей.
 2.    Провести социологическое исследование потребностей, мотивации и барьеров целевой аудитории (студентов медицинских факультетов) для формирования функциональных и содержательных требований к проектному модулю.
 3. Разработать концепцию пользовательских сценариев и структурно-содержательную архитектуру проектного модуля, направленного на пошаговую интеграцию студентов в науку с учетом их учебной нагрузки и индивидуальных интересов.
 4.    Реализовать методический и цифровой прототип проектного модуля (включая трекинг прогресса и навигацию по этапам исследования) для его последующей апробации в образовательной среде вуза.
